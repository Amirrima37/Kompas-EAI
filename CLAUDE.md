# Проект: ИИ-агент для КОМПАС-3D
Цель: чат-запрос -> черновая 3D-модель в КОМПАС-3D v24 (x64) -> уточнения -> правка.
Первая версия: базовые формы, затем параметрический шаблон кожухотрубного теплообменника.

## Среда
- Windows 11 Pro, Python 64-bit, venv в .venv, pywin32
- КОМПАС: COM API7 + API5 (Kompas.Application.7 / .5)
- Справка: help.ascon.ru/KOMPAS_SDK/24 (сверять методы, не угадывать)

## Правила
- ИИ не исполняет произвольный код: только заранее описанные инструменты
- Модель строится из JSON-спецификации (пересборка, а не правка дерева)
- Работать только в папке проекта; перед удалением/перезаписью спрашивать
- Единицы: мм. Валидировать диапазоны параметров. Логировать вызовы.
